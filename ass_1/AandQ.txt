Task 1 — Variables and Data Types

1. What is the difference between let and const?
let is used for variables that can be reassigned. const is used for variables that cannot be reassigned.

2. What does typeof null return?
typeof null returns "object". This is a historical behavior of JavaScript.

3. What are JavaScript primitive types?
JavaScript primitive types are string, number, boolean, undefined, null, bigint, and symbol.

Task 5 — Values and References

4. What happens to original when copy.score is changed? Why?
original.score also changes because copy and original reference the same object in memory.

5. What happens when a nested object is copied using spread and the city is changed?
The city in the original object also changes.

6. Why does this happen?
The spread operator creates a shallow copy. The outer object is new, but the nested address object is still shared.

7. How can the nested address be copied correctly?
The nested object should also be copied using spread.

Task 7 — Functions as Values

8. Can functions be stored in variables?
Yes. Functions can be stored in variables in JavaScript.

9. Can functions be passed to other functions?
Yes. A function can be passed as an argument to another function.

10. What is the difference between add and add()?
add refers to the function itself, while add() calls the function and returns its result.

Task 8 — Scope

11. What is global scope?
A variable in global scope can be accessed from anywhere in the program.

12. What is function scope?
A variable created inside a function can only be accessed inside that function.

13. What is block scope?
A variable created with let or const inside a block {} can only be accessed inside that block.

14. What is the difference between var, let, and const?
var is function-scoped and can be redeclared and reassigned. let is block-scoped and can be reassigned. const is block-scoped and cannot be reassigned.

Task 9 — Closure

15. Why can the inner function still access variables from the outer function?
Because of a closure. The inner function remembers the variables from the outer function even after the outer function has finished running.

Task 10 — Destructuring, Spread and Rest

16. What is the difference between spread and rest?
Spread expands values, while rest collects multiple values into one array.

Task 11 — Optional Chaining and Default Values

17. What do you notice about || and ???
|| uses the default value for any falsy value, while ?? uses the default value only for null or undefined.
