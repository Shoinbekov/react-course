Sequential vs Concurrent

Sequential execution waits for each task before starting the next task. Concurrent execution starts all tasks together.

Explanation

Synchronous code runs first on the Call Stack. Promise callbacks and code after await are Microtasks. setTimeout callbacks are Tasks. The Event Loop moves callbacks to the Call Stack when JavaScript is ready to execute them.
